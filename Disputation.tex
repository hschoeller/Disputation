% WHY: the methodological contribution of P1 in one picture;
%   this is a gap-method slide ("what could you not do
%   before").
% SAY:
% The method I developed with my co-authors needs a single deterministic
% trajectory -- simulated or observed -- and turns it into a Markov chain.
% One step of the chain is one deterministic step T followed by one random
% jump D between points of the trajectory, drawn from a diffusion kernel
% of width sigma. That jump plays the role of the noise.
%
% [CLICK]
% In the schematic, the black arrows are the deterministic progression,
% the red arrows the stochastic jumps.
%
% [CLICK]
% From the operator P, different regimes can be defined as almost-invariant
% sets,
%
% [CLICK]
% and regime lifetimes for each may be extracted by standard linear algebra.
%
% [CLICK]
% No stochastic re-simulation is needed, and the underlying dynamics never
% have to be known. Lets make this more clear given our example.

\begin{frame}{A Markov chain approach}
  \textbf{Input:} (Deterministic) trajectory $\mathcal{X} = \{X_n\}_{n=1,\hdots, N}$\\
  \textbf{Ansatz:} one deterministic step $T$, one random step $D(\sigma)$:
  \begin{equation*}
    P(\sigma) = T \circ D(\sigma), \qquad
    D(\sigma)_{ij} \sim
    \exp\!\left(-\tfrac{\lVert X_i - X_j\rVert^2}
    {2\sigma\,\dd t}\right)
  \end{equation*}
  \only<2>{\centering \includegraphics[scale=.2]{fig/chain_stochastic.png}\\
          {\tiny Courtesy R. Chemnitz}
}
  \only<3->{\begin{columns}
      \begin{column}{.6\textwidth}
        \begin{itemize}
          \item<3-> Identification of regimes as almost-invariant sets of $P(\sigma)$
          \item<4-> Regime lifetimes: linear algebra on $P(\sigma)$
          \item<5-> No stochastic re-simulation; dynamics need not be known
        \end{itemize}
      \end{column}
      \begin{column}{.4\textwidth}
        \centering
        \includegraphics[scale=.2]{fig/chain_stochastic.png}\\
        {\tiny Courtesy R. Chemnitz}
      \end{column}
    \end{columns}}
\end{frame}

% WHY: the headline result, with the mechanism and the
%   condition stated exactly. This is the mathematical heart.
% SAY:
% Applying the method gives the regime definition shown here, with the
% blocking regime clearly centred on the one-dimensional submanifold
% extending from the blocking fixed point.
%
% [CLICK]
% To arrive at regime lifetimes, the Markov chain is restricted to the 
% blocking regime, shown here by the grey points. The points where the system
% has just entered the regime are coloured here according to how far away they
% are from deterministic exit. To find their associated escape times, 
% the expected number of steps under the action of the Markov
% operator P that the system takes to leave the regime are calculated.
%
% [CLICK]
% And here is the surprise. For some entry points, escape times
% do not decay monotonically with
% noise: there is a noise level at which the blocked regime lives longer
% than without noise. The mechanism is geometric. Escape runs along that
% single unstable direction, slowly at first and then accelerating. A
% random kick against it early on is cheap for the noise but expensive for
% the escape -- it resets the slow phase. This is why this effect is more 
% pronounced for the entry points close to the blocking fixed point.
% The condition is sharp: exactly
% one unstable dimension is needed. A toy system with three unstable directions
% shows no such effect, and a forthcoming paper proves this in generality.
% The mean REGIME lifetime -- the average across all entry points -- also
% exhibits this effect and I show it more clearly in this plot.
%
% [CLICK]
% If stochastic re-simulations are performed, it turns out that this effect is
% even stronger, which means the system's exploration of the state space 
% away from the deterministic attractor amplifies this effect.
% But it is
% already there without any access to the dynamics, and the method
% captures it.

% first-order effect on the reliability of the forecast that follows.
%
% [CLICK]
% In ensemble data assimilation, the assimilation is repeated several times,
% each time with the observations and the physics parametrizations
% perturbed. Note what this is in the language of this talk: noise
% injected in observation and assimilation space, exploring the
% neighbourhood of the analysis.
%
% [CLICK]
% The spread between the members then serves as the estimate of
% assimilation uncertainty.
%
% [CLICK]
% Mechanically, that spread is governed by the precision of the
% instruments, the coverage of the observations and the growth of model
% error -- as the schematic on the right shows: smaller observation error

% constrains the model forecast. Crucially, the spread is flow-dependent:
